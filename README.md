# Oficinas LTD

Site de divulgação e inscrição da trilha de oficinas do Laboratório de Transformação Digital da Estácio.

Site publicado: https://abraaorosal.github.io/site-oficinas-ltd/

## Estrutura

- `index.html`: estrutura principal da página.
- `assets/css/styles.css`: identidade visual, layout responsivo e animações.
- `assets/js/content.js`: textos, datas e link de inscrição.
- `assets/js/app.js`: renderização dos blocos, menu mobile e animações de entrada.
- `assets/img/logo-estacio.jpeg`: logo utilizada no topo.
- `assets/favicon-32.png`: favicon para navegadores.
- `assets/favicon-192.png`: ícone para dispositivos Android.
- `assets/apple-touch-icon.png`: ícone para dispositivos Apple.

## Edição rápida

1. Ajuste textos, datas, vagas, responsáveis e link de inscrição em `assets/js/content.js`.
2. Se quiser trocar a logo, substitua `assets/img/logo-estacio.jpeg`.
3. Para trocar os ícones, atualize os três arquivos de favicon em `assets/`.

## Publicação

O site é publicado automaticamente pelo GitHub Pages a partir da branch `main`.
